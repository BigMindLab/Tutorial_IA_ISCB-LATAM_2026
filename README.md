**Multiomics, Immunoinformatics, and Protein Structural Analysis**

Hands-on tutorial for the **ISCB-SOIBIO-SPBBC LATAM Conference 2026** (Lima, Peru).
Organized by **BigMind** (Bioinformatics Group in Multi-omics and Immunology) and **RIABIApro** (CYTED Iberoamerican Network on AI for Biosciences and Biotechnology).

## Learning objectives

By the end of this tutorial, participants will be able to:

- **Understand** the basic principles and limitations of AI tools in modern bioinformatics.
- **Build and implement** AI-powered bioinformatics workflows.
- **Execute** AI-driven analyses and **predict** biological outcomes.
- **Critically interpret** AI-derived results, outputs and metrics.
- **Test and validate** AI-derived insights using complementary computational approaches.

## How to run the exercises

All notebooks run in **Google Colab** or **GitHub Codespaces**, no local installation needed.
Pre-computed results are included so every exercise also works without an API key or internet access to the model.
