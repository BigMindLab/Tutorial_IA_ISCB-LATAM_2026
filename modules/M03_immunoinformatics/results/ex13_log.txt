      LOOK AT THIS CAREFULLY. Standard deviation of the score ...
        ... when the PEPTIDE changes, TCR fixed : 0.0060
        ... when the TCR changes, peptide fixed : 0.0780

      The score barely moves when the peptide changes but it does move
      when the TCR changes. On peptides it has never seen, the model is
      essentially scoring the CDR3 and ignoring the peptide. That is the
      clearest possible demonstration that it is not answering the
      question we are asking it.

      The model RETURNS a number for every pair. None of them is
      interpretable: fhaC is not in the training set, these TCRs were
      never measured against it, and there is no HLA context in the input.
      Practical consequence for exercise 14: the TCR column for fhaC is
      marked 'no evidence' rather than filled with a score.

QUESTIONS TO DISCUSS
==============================================================================
  1. The global AUC on partition 5 is high. Looking at the per peptide
     table, why is reporting that number alone misleading?
  2. Non binders are built by pairing TCRs with random peptides. What
     bias does that introduce, and how would you notice it?
  3. The input does not include the HLA. Two people with different HLA
     and the same CDR3 get the same score. Is that right?
  4. If you wanted to use NetTCR for fhaC, what experimental data would
     you have to generate first?
